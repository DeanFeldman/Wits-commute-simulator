# Level 2 story arms

The game draws `background.png` and the selected character's transparent PNG together for the Level 2 story screen. Missing or invalid selections use Luca. Skin tones and sleeves reference the game's six student models.

Created with the built-in image generation tool. Full character prompts are in `prompts.json`. The original Level 2 story image remains available in the parent UI directory.

Five arm canvases are 1608 by 978; Naledi is 1607 by 979. Full-frame sizing keeps their placement aligned with the shared background. Each PNG has a real alpha channel.

Interactive preview: `output/arm-overlays/level2-preview.html`. All six overlays and default selection were checked with the game's presentation methods in the browser. Level 1 retains its existing arms and precise watch-face layer; Level 3 retains its existing story image.

Background localization: Takealot truck lettering, three white-and-blue Gauteng-style GP plates, additional parking bays and cars on the right, and removal of the lower-left bucket. Edited with the built-in image generation tool.
